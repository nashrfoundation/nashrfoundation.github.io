Setup Instructions

            
    
                
  1. Get MailerLite API Key:
                    
      
                        
    • Go to MailerLite Dashboard
      • 
                        
    • Sign up for a free account (1,000 subscribers, 12,000 emails/month)
      • 
                        
    • Navigate to Integrations > API
      • 
                        
    • Copy your API key
      • 
                    
    
                
    2. 
                
  2. Configure:
                    
      
                        
    • Enter your API key above
      • 
                        
    • Click "Configure MailerLite"
      • 
                        
    • Test the connection
      • 
                    
    
                
    3. 
                
  3. Update Config File:
                    
      
                        
    • Open mailerlite-config.js
      • 
                        
    • Replace the placeholder with your actual API key
      • 
                        
    • Save the file
      •
