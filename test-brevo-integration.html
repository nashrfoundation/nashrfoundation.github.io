Setup Instructions

            
    
                
  1. Get Brevo API Key:
                    
      
                        
    • Go to Brevo Dashboard
      • 
                        
    • Navigate to Settings > API Keys
      • 
                        
    • Create a new API key with "Contact" permissions
      • 
                        
    • Copy the API key and paste it above
      • 
                    
    
                
    2. 
                
  2. Get List ID:
                    
      
                        
    • Go to Contacts > Lists in Brevo dashboard
      • 
                        
    • Create a new list or use an existing one
      • 
                        
    • Click on the list to view details
      • 
                        
    • Copy the List ID from the URL or list settings
      • 
                    
    
                
    3. 
                
  3. Configure:
                    
      
                        
    • Enter your API key and List ID above
      • 
                        
    • Click "Configure Brevo"
      • 
                        
    • Test the connection
      • 
                    
    
                
    4. 
                
  4. Update Config File:
                    
      
                        
    • Open brevo-config.js
      • 
                        
    • Replace the placeholder values with your actual credentials
      • 
                        
    • Save the file
      • 
                    
    
                
    5.
